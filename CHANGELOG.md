# 0.1.0

## Initial public release

- Added a desktop-oriented app bar composition API.
- Added hover and click interaction modes.
- Added nested and cascading submenus.
- Added configurable menu and app-bar styling.
- Added keyboard bindings, modifier support, and raw keyboard callbacks.
- Added focus handling and `FocusNode` integration.
- Added programmatic menu control through `DesktopMenuController`.
- Added support for custom triggers and arbitrary menu content.
- Kept application actions outside the package so the menu system can be reused across projects.
